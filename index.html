OPENPGP · PASSWORD RECOVERY

一个口令，随时在本地找回你的密钥。

在任意设备输入同一个口令，就能重建同一份密钥材料。姓名和 Email 只写入公开的 PGP User ID，不是恢复因子；没有助记词、钱包签名、恢复文件或后端账户。

01 / PGP 身份

填写公钥中显示的身份

Ed25519 + Curve25519

姓名和 Email 会写入公开的 PGP User ID，但不参与密钥派生；Email 可不填。换姓名或 Email 不会改变密钥指纹。若要让导出的公钥证书也完全一致，需使用相同身份信息。

02 / 唯一恢复口令

Argon2id（64 MiB、3 轮）用于派生。请使用至少 16 个字符、唯一且难猜的长口令；口令区分大小写，空格会保留，字符按 NFC 规范化。长度门槛不等于强度保证。PGP 公钥可让攻击者离线验证猜测，Argon2id 只能增加每次猜测的成本。不同 PGP 身份请用不同口令，否则会复用同一把密钥。
